# Data input module

This module function has been adapted from the [Getting started: UI
input + server
output](https://mastering-shiny.org/scaling-modules.html#getting-started-ui-input-server-output)
section of Mastering Shiny.

## Usage

``` r
datasetInput(id, filter = NULL)
```

## Arguments

- id:

  module id

- filter:

  type of object (i.e. `is.data.frame` or `is.matrix`)

## Value

list of data object names
